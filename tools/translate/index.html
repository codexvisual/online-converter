Translate PDF text into 30+ languages with live preview. Download as Word, PDF, TXT or HTML. Your PDF file is never uploaded.

Translate PDF is a free browser-based translator with live preview. Upload a PDF, choose a language, and watch the translation appear instantly in over 30 languages including Bengali, Hindi, Spanish, Arabic and Chinese. Download the result as an editable Word document, PDF, plain text or HTML. Only the extracted text is sent to the translation service — your original PDF file is never uploaded. Before you begin, gather the files you want to work with and keep an untouched copy of the originals. There is no sign-up and no waiting room: the tool opens instantly and runs on your device. Very large files depend on your computer's available memory, so close unused tabs if a document is unusually big.
