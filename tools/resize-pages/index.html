Resize pages

Resize pages: Resize all pages to A4, Letter, Legal or A3. 100% free, private and client-side. No upload required.

Resize pages is a free, browser-based tool that lets you resize all pages to a4, letter, legal or a3 — without uploading your files anywhere. All processing happens locally in your browser using modern web technologies, so your documents and images stay completely private.

Before you begin, gather the files you want to work with and keep an untouched copy of the originals. There is no sign-up and no waiting room: the tool opens instantly and runs on your device. Very large files depend on your computer's available memory, so close unused tabs if a document is unusually big.

How to Use Resize pages

  1. Upload your PDF.
  2. Add text, images, watermarks or page numbers.
  3. Click Apply and download.

Key Features & Privacy Guarantee

  • Edit PDFs directly in the browser.
  • Non-destructive, local processing.
  • Free and private.
  • Undo/redo supported.

Why Use Resize pages?

Small changes should not require expensive desktop software. Browser-based editing lets you add a note, mark up a page or place a signature without installing anything.

Common Use Cases

  • Adding a watermark to a draft proposal
  • Placing page numbers on a long manual
  • Signing an agreement and sending it straight back

Tips & Best Practices

  • Save a copy before editing.
  • Use the preview to check placement.
  • Watermarks work best at 30-50% opacity.

Work on a copy of the original file so you can always start again if a change is not right.

Privacy & Security

This tool processes your file entirely inside your browser tab. Nothing is uploaded, stored on a server, or shared. The download is generated on your device, so the original file stays private.
