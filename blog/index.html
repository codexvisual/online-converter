How to Compress a PDF Without Losing Quality

PDF files grow quickly. A scan at 600 DPI, a slide deck full of photos, or a document with embedded fonts can easily pass 20 MB — too large for most email inboxes and slow to open on mobile. The good news is that most of that weight is usually unnecessary, and you can remove it without making the text unreadable.

There are two different kinds of compression, and choosing the right one matters more than any slider:

  • Lossless (structure) compression rewrites the PDF's internal objects and object streams. Text, vectors and images stay pixel-identical, but the file can shrink by 10–40%. This is the safe default for contracts, invoices, academic papers and anything that will be printed.
  • Lossy (image) compression re-encodes the page images at a lower resolution and quality. Files can drop by 70–90%, but small text may soften. This is the right choice for scanned documents and photo-heavy brochures that only need to be read on screen.

Start with lossless compression. If the result is still too large, switch to lossy and compare a page side by side before sending. A useful rule of thumb: 150 DPI is plenty for on-screen reading, 200–300 DPI for office printing, and 600 DPI only for archival scans of fine print.

If our Compress PDF tool reports that your file is already optimised, that is not a failure — it means re-encoding would make the file larger, so the original is returned unchanged.

JPG vs PNG vs WebP: Which Image Format Should You Use?

Every format is a trade-off between size, quality and features. Picking the wrong one is the most common reason a page feels slow or a screenshot looks blurry.

  • JPG is best for photographs and anything with smooth gradients. It is small and universally supported, but it has no transparency and loses a little detail every time you re-save it.
  • PNG is best for screenshots, logos, icons and images with transparency. It is lossless, so text stays razor sharp, but photographic PNGs can be five to ten times larger than the equivalent JPG.
  • WebP is the modern web format: roughly 25–35% smaller than JPG at the same visual quality, with transparency and animation support. Every current browser handles it.
  • AVIF compresses even further, but encoding is slow and older software may not open the files — better for websites than for sharing.

For a website, export photos as WebP and keep a JPG fallback. For email attachments and documents, JPG is still the safest. For design assets and screenshots, PNG wins. You can convert JPGs to PNG or WebP with our image converter or edit and export in Image Studio.

Why Browser-Based Tools Are More Private

Traditional online converters work the same way: you upload a file, a server processes it, you download the result. That model has three problems. First, your document leaves your device — for a contract, a medical record or an ID scan, that is a real privacy decision. Second, the file sits on someone else's disk, and retention policies are often vague. Third, every upload costs bandwidth and time.

Modern browsers can do the same work locally. JavaScript engines are fast enough to parse PDFs, render pages to canvas, encode images and even run OCR. When processing happens in your tab, the file never crosses the network, so there is nothing to store, log or leak.

You can verify this yourself: open your browser's developer tools, switch to the Network tab, and process a file. A local tool makes no upload request. That is the standard we hold ourselves to — and it is why Online Converter works offline after the first visit.

How to Merge PDF Files in the Right Order

Merging is simple in principle and surprisingly easy to get wrong. A few habits prevent most mistakes:

  1. Name your files with a numeric prefix (01-cover.pdf, 02-report.pdf, 03-appendix.pdf) before you start. Drag-and-drop ordering is fast, but names make the intended sequence obvious to anyone reviewing the result.
  2. Check page orientation. Mixing portrait and landscape pages is fine, but a rotated scan will look wrong in the merged document. Use the rotate control on each file first.
  3. Decide about page size. If your sources differ (A4 and Letter, for example), choose whether pages should keep their original size or be scaled to match the first page. Scaling keeps the document visually consistent; keeping originals preserves exact dimensions.
  4. Add bookmarks and page numbers afterwards if the document is long. A merged 200-page file without a table of contents is hard to navigate.

Five Small Habits That Keep Documents Safe

Privacy is mostly a set of small, repeatable habits rather than a single product choice.

  • Remove metadata before sharing — author names, software versions and GPS coordinates often travel with a file without anyone noticing. Our metadata tool shows what is inside.
  • Redact properly. Drawing a black box over text does not delete it; the text is still selectable underneath. Use a real redaction tool that removes the content.
  • Prefer tools that work offline when handling sensitive files. If a tool needs a network request to function, ask why.
  • Keep an untouched copy of the original. Compression and conversion should always produce a new file, never overwrite the source.
  • Check the file size before emailing. A 25 MB limit is common, and a compressed PDF is usually a better experience for the recipient anyway.
